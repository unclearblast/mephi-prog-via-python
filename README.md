# Анализ каталога фильмов

Учебный мини-проект: анализ каталога фильмов стримингового сервиса
без внешних библиотек анализа данных — только стандартная библиотека
Python (`math`) и ручные операции.

## Запуск

    uv run catalog_analysis.py

## Проверка стиля

    uv run ruff check .

## Что делает скрипт

- считает средний рейтинг и возраст каталога;
- строит топ-3 фильмов по рейтингу;
- группирует фильмы по жанрам;
- выводит полный список уникальных жанров;
- демонстрирует итераторы, генераторы и множества.
