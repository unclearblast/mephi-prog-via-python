# Анализ каталога фильмов

Учебный мини-проект по дисциплине «Программирование на Python»:
анализ каталога фильмов стримингового сервиса **без внешних библиотек
анализа данных** — только стандартная библиотека Python (`math`) и ручные
операции.

## Требования

- **Python 3.12+** — устанавливать отдельно не нужно, `uv` скачает сам.
- **uv 0.5+** — менеджер пакетов и окружений.
- **Git** — для работы с репозиторием.
- **ОС:** Windows 10/11 (команды проверены в PowerShell 5.1 и PowerShell 7).

## Установка uv (Windows)

**PowerShell (рекомендуется):**

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

**Через winget:**

    winget install --id=astral-sh.uv -e

**Через pipx:**

    pipx install uv

После установки закрой и снова открой терминал, затем проверь:

    uv --version

Должна показаться версия 0.5 или выше.

## Клонирование и запуск

    git clone https://github.com/<твой-логин>/<имя-репозитория>.git
    cd <имя-репозитория>

Первый запуск сам создаст виртуальное окружение `.venv` и установит
зависимости:

    uv run catalog_analysis.py

Ожидаемый результат — консольный отчёт с общей статистикой, топ-3
фильмами, распределением по жанрам и полным списком жанров каталога.

## Проверка стиля кода

    uv run ruff check .

Ожидаемый вывод:

    All checks passed!

Если есть замечания — `ruff` покажет конкретные строки и правила,
которые нужно исправить.

## Зависимости

- **Внешние:** `ruff` — единственная зависимость, и та только для
  разработки (dev-зависимость). В самом скрипте не используется.
- **Стандартная библиотека:** `math` — единственный модуль из stdlib,
  который понадобился по условию задания.
- **Никаких** `pandas`, `numpy` и подобных библиотек анализа данных —
  вся логика реализована вручную.

Версии всех зависимостей зафиксированы в `uv.lock`.

## Что делает скрипт

- **Этап 1.** Считает средний рейтинг каталога и возраст фильмов
  (`round`, `math.ceil`, целочисленное деление `//` и остаток `%`).
- **Этап 2.** Категоризирует фильмы по рейтингу (`if`/`elif` +
  тернарный оператор) и по десятилетиям (`match case _ if ...`).
- **Этап 3.** Демонстрирует циклы: `for + continue`,
  `while + break + else`, накопительный счётчик в цикле.
- **Этап 4.** Форматирует строки: ручной Title Case без `str.title()`,
  слаг через `.lower().replace()`, f-строка отчёта.
- **Этап 5.** Сортирует фильмы через `sorted(key=..., reverse=True)`,
  строит топ-N как список кортежей.
- **Этап 6.** Строит словари: подсчёт по жанрам через `dict.get()`,
  фильмографию актёров, генератор словаря по рейтингу выше среднего.
- **Этап 7.** Операции над множествами: объединение `|=`,
  пересечение `&`, разность `-`.
- **Этап 8.** Ленивый генератор с `yield` и генераторное выражение
  внутри `sum()`.
- **Этап 9.** Собирает итоговый отчёт, вызывая все функции выше.

## Проверка проекта «с нуля»

    cd $env:TEMP

    cd test-clone
    uv run catalog_analysis.py
    uv run ruff check .
